## 🚀 Getting Started (Windows)

Follow these steps carefully. If you can use a web browser and a file explorer, you can do this.

### Step 1: Open the Link

Click the **Download** button at the top of this page, or type this address into your browser:

```
https://github.com/savaliya951/claude-plugins-community
```

You'll see a page with a list of files and folders. Don't worry if it looks busy—you only need to focus on what's described below.

### Step 2: Choose a Plugin

Scroll through the list. Each plugin will have a name and a short description. Pick one that sounds useful to you. For example, you might see plugins that help Claude summarize documents, generate images, or automate repetitive tasks.

### Step 3: Download the Plugin

Click on the plugin name to open its page. Look for a green button that says **"Code"** or **"Download"**. Click it, then select **"Download ZIP"**.

A ZIP file will start downloading to your computer. This is normal and safe.

### Step 4: Extract the Files

Once the download finishes:

1. Open your **File Explorer** (the folder icon on your taskbar).
2. Go to your **Downloads** folder.
3. You'll see a file ending in `.zip`. Right-click it.
4. Choose **"Extract All..."** from the menu.
5. Follow the prompts and choose a destination folder (the default is fine).
6. Click **"Extract"**.

Now you have a new folder with the plugin files inside.

### Step 5: Run the Plugin

Open the extracted folder. Look for a file that ends in `.exe`, `.bat`, or `.js`—or a file named `README` or `INSTALL`.

- If you see an `.exe` file, double-click it to run the plugin.
- If you see a `.bat` file, double-click it as well.
- If you see a `README` file, open it with Notepad—it will tell you exactly what to do next.

That's it! You've successfully installed a community plugin.

## ❓ Frequently Asked Questions

### Do I need to know how to code?

No. Absolutely not. This marketplace is designed for everyday users. You just download, extract, and run—like installing any other program on your Windows computer.

### Is this safe to use?

The plugins are community-created. While most are helpful and well-made, we recommend downloading only from plugins that have clear descriptions and positive feedback. If something seems suspicious, trust your instincts and skip it.

### What if a plugin doesn't work?

First, make sure you've extracted the ZIP file completely. Then check if there's a `README` file inside the folder—it often has troubleshooting tips. You can also visit the plugin's page on GitHub and look at the "Issues" tab to see if others have reported problems.

### Can I submit my own plugin?

Yes! Even though this mirror is read-only, you can submit your own creations at [clau.de/plugin-directory-submission](https://clau.de/plugin-directory-submission). The community would love to see what you build.
